# Icon creation

Created with the built-in OpenAI image generation tool for this project. Original prompt:

> Use case: logo-brand. Asset type: Windows desktop app icon for FC27 Pad Lock, a controller input protection utility. Primary request: one polished original square app icon, a bold simplified game controller silhouette combined with a subtle protection shield motif, immediately legible at 32px and 16px. Style: premium flat app symbol, thick clean forms, restrained depth, a compact strong silhouette. Composition: one centered icon occupying 82% of the square, rounded square dark navy tile with bright cyan/white controller and small protective shield badge. No letters, no numbers, no words, no watermarks, no EA/Steam/PlayStation/Xbox or other brand logos. Solid square image, no surrounding mockup, no grid, no variants.

PadLock.png is the generated source image. scripts/make-icon.ps1 converts it into a multi-size Windows ICO for packaging. No third-party brand assets are included.
