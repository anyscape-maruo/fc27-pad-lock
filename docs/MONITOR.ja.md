# FC27だけの入力監視

監視は入力保護を変更しない独立モジュールです。通常は統合アプリが自動で起動・終了します。FC27・FC27_Trial・FC27_Showcaseが前面にある場合だけ、キーボードとマウスのイベント件数を集計します。他アプリの入力内容をログに保存しません。

オーバーレイでは、観測開始からのキーボード／マウス別のチェーン遮断・通過件数、監視状態、最近の注意を確認できます。通常の退避キーや他アプリから押し続けたキーなど、意図した通過も件数に含まれます。

## 検知する内容

| 分類 | 意味 |
| --- | --- |
| ガード停止 | 状態が停止を示す、または対応するガードプロセスの終了を確認した。 |
| 状態更新の途絶 | 正常な状態情報が5秒以上更新されない。ガードや保存処理の確認が必要。 |
| フック・スレッド停止 | 登録状態や処理スレッドが停止を示す。 |
| 通常入力の通過 | ガードが稼働を報告しているとき、通常の非退避入力がフックチェーンを通過した。ゲームが受け取った証明ではない。 |
| 注入入力の通過 | リマップソフトなどの入力が通過した。現在のガードの対象外として情報を記録する。 |
| Raw Inputとフックの不一致 | Raw Inputは観測できたがフック側の件数がない等。観測経路の違い・監視不調の疑いで、失敗の確定ではない。 |

通常のマウス移動の通過だけで警告を増やしません。ユーザーが許容したFC27のカーソル表示を、試合操作への切り替えと混同しません。

## 分からないこと

監視はフックチェーンが返した結果を観測し、自分では入力を止めません。遮断したソフトがこのガードか別ソフトかは確定できません。ゲームプロセスにコードを注入せず、ゲームのメモリーやメッセージキュー内部を読みません。選手操作や機器切り替えの実際の失敗を外部から確定する機能はありません。

`actualMatchFailureDetected` と `gameInternalArrivalKnown` はfalseです。「通過」「注意」は入力機器が切り替わったという確定表示ではありません。

## 保存と通知

`%LOCALAPPDATA%\FC27PadLock` に `monitor-status.json` と最大1000行の `monitor-events.jsonl` を保存します。文字内容・キー番号・座標・デバイスIDは保存しません。状態の一時的な読取失敗は、最後の正常なハートビートの有効期限内で扱います。

統合パネル・オーバーレイで状態を確認できます。独立監視メニューを開いた場合は、新しい警告を通知領域の通知でも案内します。Windowsの通知設定やゲーム中の通知抑止で、通知が表示されない場合があります。記録自体はローカルに残ります。
