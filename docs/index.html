まずは、この3つだけ
  1. FC27 Pad Lockをインストールする。
  2. アプリを開く。保護は自動で有効になります。
  3. FC27を起動し、コントローラーで遊ぶ。

利用マニュアル

目的と必要環境

FC27が前面にあるとき、キーボード・マウスを触ってしまうことで操作が変わる問題を軽減するための入力ガードです。コントローラーを選択する機能や、FC27が認識していないコントローラーを認識させる機能はありません。

対象の実行環境はWindows x64と.NET Framework 4.xです。Windows 11の実機で確認しています。ゲーム側で使いたいコントローラーを認識できる状態を用意してください。Steam版はパネルから起動できます。その他の配信版はゲームを通常の方法で起動し、ガードの対象プロセス名に一致する場合に保護します。その他の配信版は未検証です。

1. 展開と初回確認

通常の導入はReleaseの FC27PadLockSetup.exe を実行します。管理者権限不要でユーザー専用にインストールし、デスクトップとログイン時起動の登録を選べます。アプリ起動時に保護が自動で有効になります。以下はポータブルZIPを使う場合の手順です。

  1. Releaseの FC27PadLock-v0.1.0-preview.3-win-x64.zip をダウンロードします。
  2. 「すべて展開」でフォルダーを展開します。ZIPの中から直接実行しないでください。
  3. フォルダー内の Start.cmd をダブルクリックします。直接 build/FC27PadLockControl.exe を開いても同じ操作パネルが表示されます。
  4. コントローラーを接続します。通常のFC27で認識されることを確認してください。
  5. FC27のメニューで「30秒試験」を使い、コントローラーが動くか、キーボード入力とマウスクリックが抑止されるか確認します。試験は30秒で自動終了します。
  6. 問題なければ「保護を有効」を押します。この操作には自動終了の時間制限がありません。

この版の実行ファイルは署名なしです。Windowsに警告が出る場合、配布元とハッシュを確認して判断してください。セキュリティソフトの無効化や、システム全体の設定変更は導入手順に含みません。

2. 試合を始める

  1. アプリを起動し、パネルで「保護は有効」を確認します。一時解除や停止をしていた場合は「保護を有効」で再開します。
  2. Steam版はパネルの「FC27を起動」を押します。Steamの標準URIを使うため、Steamを別のドライブへインストールしていても固定パスには依存しません。
  3. 最初の画面から使いたいコントローラーで操作し、Clubsなど目的のモードへ進みます。
  4. 試合でコントローラーの選手操作が続くか確認します。キーボード・マウスにすでに割り当てられたセッションを、このツールがコントローラーに変更することはありません。

ゲームが既に開いているとき、「FC27を起動」はゲームを再起動する操作ではありません。試合中にゲームを閉じる操作は行わず、必要なら試合終了後に通常の方法で終了してから起動し直してください。

3. 操作パネル

操作 結果
保護を有効 期限なしの保護を起動、または再開します。実行中の30秒試験から切り替える場合は試験を終了して保護を起動します。
一時解除 ガードを常駐させたまま、入力抑止を解除します。
保護を停止 ガードを終了します。操作パネルは残ります。
FC27を起動 保護の稼働状態を確認してからSteam版FC27を開きます。
FC27へ戻る ゲーム窓を前面にします。キーボード入力は送信しません。
30秒試験 保護を30秒間だけ有効にし、自動終了します。
右上の× パネルだけ隠します。常駐は続きます。

通知領域の盾アイコンをダブルクリックするとパネルを開けます。Windowsの通知領域に隠れている場合は「隠れているインジケーター」から探してください。

新版の画面はダッシュボード／表示・オーバーレイ／入力・解除キー／常駐・通知／サポートに分かれています。アイコンの右クリックでは専用クイックパネルが開きます。テーマ・通知間隔・自動起動・オーバーレイ倍率と余白などはアプリ設定を参照してください。設定は再起動後も引き継ぎます。

専用アイコンはコントローラーと盾・鍵を組み合わせた青いアイコンです。パネルの「ゲーム内に状態を表示」でオーバーレイを切り替え、隣の選択欄で4隅から位置を選べます。初期設定は右上・簡易表示・不透明度50％です。オーバーレイを非表示にしても入力保護は変わりません。詳しくはオーバーレイを参照してください。

「保護は有効」はガードの状態とフックの登録情報に基づく表示です。FC27内の入力機器や試合成功を読み取った表示ではありません。

4. 他アプリを使う・入力を解除する

  • Alt+Tab / Alt+Shift+Tab：他アプリへ移ります。逆方向に切り替えるときはAlt→Shift→Tabの順で押してください。Shiftから押すとShiftが抑止され、通常のAlt+Tabになります。前面がFC27以外なら、そのアプリで通常入力を使えます。
  • Ctrl+Alt+F12：保護の有効／一時解除を切り替えます。
  • Windowsキーとその組み合わせ：退避用に通します。
  • ゲーム内のポーズはコントローラーで操作してください。Escなど通常のキーは保護中に抑止されます。

背景に見えているFC27の上へのクリック・スクロールも抑止します。他アプリで押し始めたキー・ボタンの解放は通し、FC27で抑止した押下の解放は抑止するよう追跡します。

終了するときは通知領域を右クリックして「終了して保護解除」を選びます。パネルを閉じるだけでは保護を解除しません。

アプリを終了してから起動し直すと、自動で保護を有効にします。常駐中にパネルを開き直す操作は、一時解除・停止の状態を維持します。起動に失敗した場合はエラーを表示し、「保護は有効」とは表示しません。

5. Windows起動時に使う

Setupで「Windowsログイン時に常駐する」を選ぶか、パネルの「常駐・通知」で自動起動を有効にしてください。パソコンにログインすると保護アプリが起動します。

ポータブル版で登録する場合

フォルダーを移動しない保管場所へ置いてから、フォルダーを開いてPowerShellで以下を実行します。この指定は今回のPowerShellプロセスだけに作用します。

powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1

デスクトップに「FC27 パッド保護で起動」「FC27 パッド保護パネル」を作り、ログイン時の常駐を登録します。登録処理だけでは今のゲームを再起動しません。

デスクトップのショートカットだけ必要なら、次のように自動起動を省略できます。

powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1 -NoStartup

同名ショートカットが別の場所のアプリを参照している場合は上書きせず終了します。旧版を通常の方法で解除してから登録してください。

6. 更新・削除

配布版は初期設定で自動更新が有効です。起動時と6時間ごとにGitHub Releasesを確認し、新版を準備します。通常の自動更新はゲーム終了後に切り替わります。「常駐・通知」の更新欄から手動で確認することもできます。

Setup版の削除はWindowsの「設定」→「アプリ」→「インストールされているアプリ」から「FC27 Pad Lock」を選んでください。

ポータブル版を手動で更新・削除する場合

更新は、新版を別フォルダーに展開→旧版で「終了して保護解除」→旧版の Uninstall.ps1 で登録解除→新版を起動・確認→必要なら新版の Install.ps1 で登録、の順です。同じWindowsユーザー・ログインセッションではガードを1つだけ動かします。

powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Uninstall.ps1

解除スクリプトは同じユーザー・ログインセッションの常駐終了を待ち、今回のフォルダーを参照している登録済みショートカットだけ削除します。終了を確認できない場合はエラーとして止まります。ゲーム設定やセーブを復元・削除する操作はありません。

登録解除後、展開フォルダーは手動で削除できます。状態ファイル %LOCALAPPDATA%\FC27PadLock は診断用に残ります。必要な記録がなければ、常駐終了後にこのフォルダーも手動で削除できます。

7. ハッシュ確認

Releaseの SHA256SUMS.txt と比較します。

Get-FileHash .\FC27PadLock-v0.1.0-preview.3-win-x64.zip -Algorithm SHA256

困ったときはトラブル対処を参照してください。
