トラブル対処

状況 確認・対処
FC27でキーボードが効かない 保護中の意図した動作です。必要ならCtrl+Alt+F12で一時解除し、パネルの表示を確認してください。
他アプリを操作したい Alt+Tabで前面を切り替えます。背景のFC27上へのクリックは抑止します。
マウスカーソルが動く FC27の独自入力経路では表示が動く場合があります。クリック・選択・試合操作まで届いているかを区別してください。
Edgeや別コントローラーも動かない Ctrl+Alt+F12で一時解除し、通常のFC27で使えるか確認してください。リマップソフトでボタンをキーボードに変換していないかも確認します。試合中の無理な再起動は避けてください。
試合でキーボードへ切り替わる 保護が有効か、30秒試験が終了していないか確認します。ゲームセッション開始時からコントローラーで操作しても再現する場合は未対応の入力経路として報告してください。
パネルに「状態確認が遅れています」「状態不明」と出る 保護が効いていると断定しないでください。一時解除または通知領域から終了し、ゲーム外の状態で起動し直します。
「FC27を起動」で開かない Steamがインストールされ、Steamのリンクを開けるか確認します。保護の起動が確認できない場合も起動を中止します。EA app等は手動起動してください。
パネルを閉じても保護が続く ×はパネルを隠す操作です。通知領域から「終了して保護解除」を選びます。
ショートカット登録が衝突する 同名ショートカットが別フォルダーを参照しています。旧版の登録を解除してから新版を登録します。
EXEが見つからない Source code ZIPではなく、Releaseのwin-x64 ZIPを展開したか確認します。build内の2つのEXEが必要です。

解除キーでも困ったとき

Alt+TabやWindowsキーでFC27から離れ、通知領域のメニューから終了してください。それでも必要ならWindowsのタスクマネージャーで FC27PadLock.exe を終了します。フックはこのプロセスに所属します。ゲーム自体やコントローラーのドライバーを終了・削除する必要はありません。

報告に必要な情報

GitHubのBug reportを使い、バージョン、Windows、ゲーム配信元、コントローラー名・USB/Bluetooth、ゲームモード、保護の状態、再現手順を記載してください。

「Escの表示が出た」「カーソルが動いた」と「実際にキーボードで選手を操作できた」は別々に書いてください。状態ファイルやerror.txtを共有する場合は、ユーザー名・絶対パス・その他の個人情報を取り除いてください。ゲームのセーブや認証情報は不要です。

このマニュアルはネット接続なしで読めます。GitHubのリンク先はネット接続が必要です。
